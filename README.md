## 👋 About Me

Hi, I'm **Rozhin Lajevardi** — a **Genetics graduate and web designer / frontend developer** interested in building modern, useful digital products.

My current focus is frontend development with **Nuxt, Vue, JavaScript and Tailwind CSS**, while continuing to strengthen my understanding of application architecture, APIs, authentication, state management and backend development.

I enjoy the part where **design becomes a real, working interface** — clean layouts, thoughtful interactions, responsive behavior and code that is understandable enough to keep improving.

My background in genetics also keeps me interested in the intersection of **technology, healthcare and life sciences**.

### What I'm Building Toward

| Area | Current focus |
|---|---|
| **Frontend** | Nuxt, Vue, JavaScript, responsive UI and component-based development |
| **UI / Web Design** | Figma, Tailwind CSS, WordPress, Elementor and modern minimal interfaces |
| **Application Development** | Authentication, APIs, Pinia, forms, admin panels and reusable components |
| **Backend** | Learning Django and Python to understand full-stack application development |
| **Life Sciences + Tech** | Exploring the intersection of genetics, healthcare and software |
| **Workflow** | Git, GitHub, VS Code, debugging and learning through real projects |
